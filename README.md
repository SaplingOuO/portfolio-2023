# 📌 Portfolio 2023 - Anime Record (邁向組件化開發的起點)

這個專案是我在 2023 年正式從傳統網頁開發轉型至現代前端框架的「里程碑作品」。專案的前身是我使用 Adobe Dreamweaver 以傳統 HTML/CSS/JS 建立的動漫紀錄網頁；在這個版本中，我將其核心功能重構為 Vue 3 的組件化架構，並命名為 `AnimeList`。這個專案完整記錄了我理解「數據驅動視圖」與前端資料處理的扎實過程。

---

## 🛠️ 核心技術棧 (Tech Stack)

* **核心框架**：Vue 3 (Options API 實戰探索)
* **本地資料庫方案**：LocalStorage & JSON 數據序列化
* **UI 佈局**：Bootstrap 5 (響應式卡片與彈窗元件)
* **專案建構**：Vue CLI (Webpack 5)

---

## 🌟 開發轉折與底層工具反思

### 📐 從 Dreamweaver 到 Vue 3 的思維重構
在開發此專案之前，我的核心技術僅限於靜態網頁與原生 JS 操作 DOM。藉由這個專案，我第一次體會到 Vue 3 的「數據驅動（Data-Driven）」魅力，學會如何透過調整陣列資料來即時改變畫面，並成功將原本雜亂的 HTML 結構拆解為可複用的 Vue 元件。

### ⏳ Webpack 的痛點與未來迭代契機
在此專案（Vue CLI / Webpack 環境）的開發過程中，我深刻體會到傳統打包工具在編譯、熱更新（HMR）以及輸出時漫長的等待時間。這段「卡頓」的開發痛點，成為我日後在 `portfolio-2025` 中果斷捨棄 Webpack、全面擁抱現代化極速建構工具 **Vite** 的核心動機。

## 🧪 前端核心功能與漸進式架構策略

在這個作品集中，最核心的功能模組為 **AnimeList 動漫紀錄系統**：

| 功能項目 | 技術實作 | 架構設計與開發反思（面試精華點） |
| :--- | :--- | :--- |
| **漸進式本地資料庫** | ‧ LocalStorage 永續儲存<br>‧ JSON.parse & stringify 序列化 | **以 JSON 替代線上資料庫的彈性策略**：<br>在開發初期，為避免同時學習 Vue、後端資料庫與 API 驗證而導致焦點模糊，我策略性改採 **JSON 格式結合 LocalStorage** 實作資料本地化。這不僅讓我能專注於 Vue 核心邏輯的養成，且 JSON 格式與現代 NoSQL 資料庫具備高度相容性，確保了未來系統升級時資料能無縫遷移。 |
| **多維度前端篩選系統** | ‧ 計算屬性 (`Computed`)<br>‧ `v-model` 雙向綁定 | **即時非同步過濾邏輯**：<br>實作多條件複合式篩選，使用者可同時依據「文字關鍵字」、「年份下拉選單」與「季度單選按鈕」進行即時前端資料過濾，提供流暢且不需刷新頁面的互動體感。 |
| **動態追番筆記模組** | ‧ Bootstrap 5 Modal 整合<br>‧ 陣列查重與動態更新 | **跨組件動態狀態注入**：<br>點擊特定動漫卡片時，動態將該卡片資料注入 Bootstrap 彈窗中；並在儲存筆記時，利用 `findIndex` 實作資料查重機制，判斷應執行「更新既有筆記」或「新增筆記」之邏輯，確保本地資料庫的正確性。 |

## 📈 2023 專案的迭代與成長意義

`portfolio-2023` 對我而言是一次關鍵的技術蛻變。雖然它留下了許多青澀的痕跡（例如安裝了未使用的套件、Webpack 打包效能不佳等），但它幫我開闢了全新的前端視野。
在這裡學到的 **LocalStorage 資料狀態控制、JSON 數據流處理、以及複合式前端篩選演算法**，全部轉化為我日後在 2024、2025 年開發更複雜、效能更高（Vite / Vuex / GSAP）作品集時最穩固的底層養分。
